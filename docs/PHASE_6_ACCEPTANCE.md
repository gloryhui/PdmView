# Phase 6 原生 ER 画布验收

## 表节点和关系绘制

- P6-01 使用正式图场景中的表名、编码、字段原始类型和 PK/FK 标记。表矩形和关系路径仍使用源坐标。绘制使用统一的相机变换，在世界坐标减去视口原点后转为窗口 DIP。Graph 和 Renderer 定向测试、vet 与格式检查通过。提交 `0f794df`。
- P6-02 先画关系，再画表节点。选中表时高亮相邻关系，选中关系时高亮当前关系。只有逻辑外键方向与图元的已解析端点一致时才画箭头。合成用例验证反向、重复定义和缺失引用时省略箭头。三份公开 XML 的 23 条关系及 56 个原始路径点逐项一致。Graph 和 Renderer 定向测试、vet 与格式检查通过。提交 `4c36450`。
- 本地业务样本包含一张画板、8 个表图元、90 个图上字段和 0 个关系图元。关系核验使用单独的公开导出和合成数据。业务样本在本机只读使用，SHA-256 与 Phase 3 样本记录一致。

## LOD、缓存和裁剪

- P6-03 以有效投影比例 `camera.Scale × 表宽中位数 / 236` 切换远、中、近档，回滞区间仍为 `0.36–0.44` 和 `0.75–0.85`。BVH 查询保留穿过视口的线段，查询边界包含描边和箭头包络。字段按卡片可用宽高显示，中景最多两行，近景最多五行。
- 每个画板缓存最多 256 个表视觉和 512 个共享文本条目。先预排版 64 个表，后续在绘制外按需准备。超过容量时，按加入顺序淘汰，优先保留当前选中和可见表。暂未准备文字的表继续绘制卡片。网格使用一块按缩放密度与主题替换的 32～256 像素纹理。
- 760×560 DIP 下逐个适应业务样本的表图元。旧版在第一个图元停留远景且绘制 0 字段行。新版 8/8 图元均进入近景并绘制字段行。原生 50 表、100 边密集图短测采样 5 秒，回调 60.00 FPS，帧间隔 P95 为 17.163 ms，覆盖远、中、近各 44、111、145 帧，网格命中 300/300。原始记录为 `.out/phase6/p6-03-smoke.log`。
- Graph、Renderer、UI 与基准包测试通过。Graph 和 Renderer 的 vet 与格式检查通过。提交 `0fd43c8`。

## 多画板和视口工具

- P6-04 通过原生文件面板或命令行路径打开本地 PDM。按模型和包内顺序列出画板，优先采用模型指定的默认画板。后台准备当前画板的图和 BVH。切换时丢弃旧渲染器，过期结果不能覆盖当前画板。无画板时显示自动布局，混合布局也会标明含自动布局的表。
- 在 macOS 原生窗口逐个点击按 XML 矩形独立算出的中心点。业务样本 8/8 表图元命中。公开 16.5 导出的默认画板为列表中的第二张，原生窗口按默认项打开并完成三画板切换，8/8 表图元和 13 个避开表节点的原始关系路径探测点通过。两份样本均通过拖动、滚轮平移、鼠标锚点缩放、适应选中、显示全部和重置。切换和重置清除旧选中，显示全部保留选中。
- 2× GPU 原生截图核对了表标题、编码、字段类型、PK/FK 标记与相邻关系高亮。原生文件面板成功打开公开夹具。再次打开并取消后，三画板列表与画布仍可见。取消后的具体活动画板未在文件面板测试中单独确认。
- UI、i18n、应用入口的测试和 vet 通过，覆盖 800×600 双语控件、过期加载及画板切换、非零画布原点命中、悬停离开和自动布局。按 `ui_content_minimalism` 清单移除了文件面板的重复说明。保留简短的加载、打开失败及自动布局状态，以便区分等待、失败和生成的位置。
