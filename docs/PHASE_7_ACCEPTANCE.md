# Phase 7 原生工作区验收

## P7-01 三栏工作区

- 原生窗口以 800×600 DIP 为最小窗口尺寸。左右栏有独立滚动区，可拖动分隔线并用方向键调整。主工具栏保留五个视口操作，短标签适合窄栏，辅助功能提供完整动作名。
- `CGO_ENABLED=0 go test -count=1 ./internal/ui ./internal/i18n ./cmd/pdmview`、对应 `go vet` 和 `make format-check` 通过。测试核对分隔线、缩放、相机原点和选中状态。
- macOS 原生窗口从 1200×828 DIP 缩至 800×600 DIP，内容截图为 1600×1144 像素。合成双画板模型中，双向切换简体中文与英文，五个工具均位于画布宽度内，画板和选中表保持，偏好文件两次更新。截图和帧日志保存在 `.out/phase7/`。

## P7-02 模型树与 Package

- 原生 Outline 使用领域对象 ID，默认展开模型根节点。表选择优先定位当前画板，否则按画板顺序切换。未绘制的表仍可选中并查看详情，画板保留原有几何。
- 包级测试覆盖跨画板请求失效、当前画板优先、画布到树的反向选择、无图元画板的所属 Package，以及千表树目录。相关 `go test`、`go vet` 与格式检查通过。
- macOS 原生合成夹具验证两级 Package 展开与折叠、折叠保留选中表、跨画板选择、未绘制状态。本地样本逐表验证 13/13，含 8 个可定位表与 5 个未绘制表。

## P7-03 表详情与字段列表

- 在后台建立领域对象索引。右栏显示 Package 路径、表注释、源字段顺序、数据类型及属性、键、带排序方向的索引和跨 Package 外键。保留源属性的缺失、空字符串和布尔值区别。
- 测试核对复合键、索引列和外键映射顺序，以及越界引用不被错误解析。`go test`、`go vet` 与格式检查通过。
- 本地样本通过原生无障碍树与 XML 逐项对照，涵盖 13 张表和 149 个字段。字段顺序及原始类型、长度、精度、小数位和默认值全部一致。
- 合成夹具在 800×600 DIP 验证两种语言、可独立滚动至外键属性、语言切换保留详情滚动位置，以及默认值缺失与显式空字符串的区别。

## P7-04 搜索与定位

- 包级测试验证六种搜索字段、大小写忽略、确定顺序和去重。纳入文档及查询令牌、单表长列表查询取消、键盘原生搜索、虚拟列表及相机动画打断。`go test`、`go vet` 与格式检查通过。
- macOS 原生合成夹具逐个验证六种匹配入口、跨画板切换、画布移开后的同画板回中、未绘制表详情及双语无结果状态。
- 1,000 表、50,000 字段的合成模型上，命中全部表的查询首屏构建 23 个结果行。连续录入宽泛查询及唯一表编码，从首次录入到原生无障碍树显示最新结果，中位数 34.1 ms，范围 23.6–56.2 ms，共五次。该时间包含原生 UI 与验收脚本的通信开销。

## P7-05 完整信息复制

- 详情栏顶部的「复制表信息」随详情滚动保持可见。剪贴板使用 MyGo v0.10.0 的 `Clipboard.Write(transfer.TextData(text))`。纯文本采用固定字段名和源顺序，保留 Unicode 及引用标识，区分缺失、显式空字符串和 `false`。
- 定向测试验证字段、键、索引、复合外键和规则的顺序与内容，覆盖换行、引号、反斜杠、未解析引用、未绘制表复制，以及注入剪贴板写入失败后的可访问提示。切换选中表会清除上次复制结果。
- 在 800×600 DIP 原生窗口中，滚动至详情底部后分别用英文和简体中文复制合成夹具。两次写入均显示对应语言的成功反馈，系统剪贴板读回的 3,058 个 UTF-8 字节完全一致。验收脚本恢复原系统剪贴板，并逐项核对剪贴板类型和原始字节。

## Phase 7 集成验收

- 2026-11-21，Go 1.27.4、MyGo v0.10.0、`CGO_ENABLED=0`。`make check`、`go test -count=1 -tags e2e ./...`、macOS arm64 常规与 e2e 构建通过。
- 原生工作区复测覆盖最小窗口的中英文标签、偏好双向保存、选中表与画板保持、独立滚动、搜索和系统剪贴板。以仅有预期结果出现作为终点，千表模型的连续查询复测中位数为 34.4 ms，范围 29.2–34.8 ms，共五次。
- 画布回归覆盖本地样本 1 个画板、8 张表，以及公开 XML 的 3 个画板、8 张表、13 个关系路径命中。适应选中、显示全部、指针缩放、拖拽、滚动平移及重置均通过。
- 双语界面文案核对包括操作名、空结果、未绘制状态和复制反馈。合成夹具截图及日志保存在 `.out/phase7/`。本地业务样本 SHA-256 与 Phase 3 一致。
- P4-03 的 PowerDesigner 应用内对照仍为 `BLOCKED`。Gate 3 的单表与全库 SQL 一致性随 Phase 8 生成器和 Phase 9 集成验收。
