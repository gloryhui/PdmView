## 表图元配色与字段显示

- 画板默认格式来自 `DisplayPreferences` 的 `Symbol\TABL` 段，图元 `FillColor`、`LineColor`、`FontList` 等可以逐表覆盖。十进制颜色按 Windows 低字节为红的格式解析，`0` 为显式黑色。
- 字段显示读取 `DisplayPreferences` 的 `Object` 段及图元 `SymbolContent`。覆盖列显隐、全列或键列筛选、启用的行数限制、数据类型、键标记、可空状态及已保存的标型或注释。未启用的行数限制不会裁减字段。详情、复制与 SQL 仍使用完整字段。
- 可读缩放下，完整的已选字段按源图框高度统一排版。文字、行距和矩形随视口同步缩放，远距显示图元底色与轮廓。保留常见线性渐变的两个端点色，渐变方向采用顶部到底部的近似。当前使用本机字体排版；未核定的名称／编码模式、自定义图形、复杂字段格式和自由文本注释图元仍待对照。
- macOS 原生 `e2e` 画布使用同一张合成表的三个图元。2× 截图的表卡填充 RGB 分别为 `(255,255,0)`、`(204,204,255)`、`(255,128,128)`，逐行测得显示 `9`、`3`、`0` 个字段。可见中文、数据类型及主键标记。合成夹具与截图位于 `.out/p4-table-appearance/`。
- `make check`、`e2e` 标签定向测试和四份 XML 样本回归通过。原生画布复测本地样本 8/8 表图元，以及公开样本 4/4 表图元和 2/2 条关系线。两份样本均通过缩放锚点、拖动、滚轮平移、适应、显示全部和重置。源样本 SHA-256 与 Phase 3 一致。
- PowerDesigner 的显示偏好包含图元格式和内容设置。用户配置中也可能存在仅存于 Windows 环境的偏好。参见 [SAP 显示偏好](https://help.sap.com/docs/SAP_POWERDESIGNER/856348b84a7c479489d5172a630f014d/c7c95dd96e1b1014a9d6809481364955.html)及 [用户配置](https://help.sap.com/docs/SAP_POWERDESIGNER/abd3434b4987485c92057ab9392aadbe/c7e100446e1b10149dab8a8f1bf7684b.html)。

## 本地复现

```sh
mkdir -p .local/phase4
PDM_LAYOUT_SAMPLE="$PWD/pdm_file/yian.pdm" PDM_LAYOUT_DETAILS=1 CGO_ENABLED=0 \
  go test -tags pdm_layout_check -run '^TestDiagramXMLSample$' -count=1 -v ./internal/graph \
  > .local/phase4/yian-layout.log
shasum -a 256 -c .local/phase3/sample.sha256
```

把 `PDM_LAYOUT_SAMPLE` 指向 `.local/phase3/public/` 中的本地公开导出，可以复现关系路径检查。详细输出包含图元 ID 和坐标，应重定向至 Git 忽略的本地报告。
