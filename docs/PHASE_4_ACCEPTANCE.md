## PowerDesigner 应用内对照

**截图对照已完成，P4-03 仍为 `BLOCKED`。** 用户提供了同一份 PDM 在 PowerDesigner 和 PdmView 的画板截图。在宽度统一为 2048 像素的副本上测量五个同名表的矩形中心，拟合得到横轴比例约 `+0.834`，纵轴比例约 `−0.833`，最大中心残差分别为 `0.68 px` 和 `0.29 px`。左侧同列两个表的垂直顺序互换，原画板底部的三个相邻表显示在 PdmView 顶部。结果确认原投影造成纵向镜像。截图仅用于本地比对。

投影层统一转换表框和关系折线的 Y 轴，来源记录保留原始整数。截图用的原始 PDM 尚待本机复测。PowerDesigner 应用内的实际字段显示、折线路径及原始单位到显示尺寸的标定仍待 Windows 本机对照。关系对照可用上表任一含路径的导出文件补测。

## 回归验证

- DeepSeek 实现 P4-02，主 Agent 审查、补充同一画板中同表多图元的端点断言并集成。合成回归覆盖模型及 Package 作用域、同表不同图元、缺失或歧义端点、坐标与字段顺序、确定性回退和原始数据副本。
- 有效布局转入向下为正的世界坐标。缺失几何的节点使用四列网格，卡片基线为 236 × 144 个世界坐标单位。原始几何副本使用 `int64`，超出 `float64` 整数精确表示范围的坐标在场景投影中可能舍入。
- `CGO_ENABLED=0 go test -count=1 ./internal/graph ./internal/pdm`、两包 `go vet`、`make check` 及 `go vet -tags pdm_layout_check ./internal/graph` 均通过。单独运行四份样本的 XML 对照均通过。
- 原样本 SHA-256 与 Phase 3 一致。Git 忽略规则已核实，样本及逐图元日志留在本机。
- 纵轴修复后，`make check` 通过。四份样本复核 45 个表框、23 条关系和 56 个路径点的原始整数及场景投影，135/135 次多档缩放命中正确。三份公开导出在内存中移除路径后，23/23 条关系安全重建。
- 用同一公开样本在 macOS 原生画布对照。旧构建在预期投影位置命中失败，修复后 4/4 表框和 2/2 条关系线命中。本地 `yian.pdm` 的 8/8 个表框亦命中。两次修复后走查均通过适应、显示全部、鼠标缩放锚点、拖动与滚轮平移及重置。日志和截图保存在 `.out/p4-y-axis/`。

## 本地复现

```sh
mkdir -p .local/phase4
PDM_LAYOUT_SAMPLE="$PWD/pdm_file/yian.pdm" PDM_LAYOUT_DETAILS=1 CGO_ENABLED=0 \
  go test -tags pdm_layout_check -run '^TestDiagramXMLSample$' -count=1 -v ./internal/graph \
  > .local/phase4/yian-layout.log
shasum -a 256 -c .local/phase3/sample.sha256
```

把 `PDM_LAYOUT_SAMPLE` 指向 `.local/phase3/public/` 中的本地公开导出，可以复现关系路径检查。详细输出包含图元 ID 和坐标，应重定向至 Git 忽略的本地报告。
