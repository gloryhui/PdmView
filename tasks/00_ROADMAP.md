  |
  v

  |                                  |
  +----------------------------------+
                 |
                 v

                 |
                 v

                 |
                 v

                 |
                 v

## 阶段原则

- P0～P2 必须先完成，确认 Native UI 和大型画布技术路线可行。
- Phase 1 先建立原生窗口（P1-01），再由 P1-04 接入双语资源、语言切换和本地偏好。三栏原型（P1-03）使用该机制。P1-02 绘制验证可以独立推进。
- P3 可与 P1/P2 的部分非 UI 工作并行，但必须使用真实样本验证。
- P4 完成后冻结核心 Domain Model，再大规模并行。
- P5/P6 必须依赖统一模型和 Diagram 映射。
- P7 依赖 PDM 模型和基础 UI。
- P8/P9 与画布 UI 可在接口冻结后并行。
- Phase 7 的详情、搜索、复制反馈和 Phase 9 的 SQL 预览、导出界面都复用 Phase 1 的文案资源及语言状态。
- P10 在首版功能集成后验证两个交付平台，包含双语覆盖、即时切换和重启恢复。

## 完成定义

每个任务都必须满足：
- 代码已落地。
- 测试已运行。
- 文档已更新。
- 主 Agent 审查通过。
- 任务状态表更新。
- 不存在未披露的占位实现。
