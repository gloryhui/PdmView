# Phase 10：跨平台、稳定性与发布

## P10-01 macOS Apple Silicon
验证：
- 原生启动和退出。
- 文件选择器、剪贴板。
- 中文字体和中英混排。
- Retina/HiDPI。
- 鼠标滚轮、触控板缩放。
- 大模型画布性能。
- 长时间使用内存稳定。
- 无 WebView 依赖。

## P10-02 Windows x64
验证：
- 编译、启动、退出。
- D3D11 后端。
- 文件选择器、剪贴板。
- 中文字体。
- DPI 缩放。
- 鼠标滚轮。
- 大模型性能。
- 杀毒软件/系统权限导致的文件问题提示。

## P10-03 文档与发布
- README：功能、截图、支持范围、已知限制。
- DEVELOPMENT：环境、构建、测试。
- RELEASE：版本号、构建产物、校验和。
- 不把真实 PDM 测试样本放进发布包。
- 依赖许可证核查。
- 记录 Go/MyGo/Lobe MyGo 的实际版本。
- 明确哪些 PDM 版本经过真实样本验证。
- 明确 MySQL 版本和类型映射限制。
