# Phase 10：跨平台、稳定性与发布

## P10-01 macOS Apple Silicon
验证：
- 原生启动和退出。
- 文件选择器、剪贴板。
- 中文字体和中英混排。
- 按 Gate 5 验证首次启动语言、原生菜单双向切换、偏好重启恢复和双语文案覆盖。
- Retina/HiDPI。
- 鼠标滚轮、物理触控板双指捏合缩放。
- 大模型画布性能。
- 长时间使用内存稳定。
- 按 [Gate 5](../QUALITY_GATES.md#gate-5跨平台和发布) 验证应用界面完全使用原生 UI 且未创建 WebView，记录 macOS 启动时系统 WebKit 的加载来源。

## P10-02 Windows x64
验证：
- 编译、启动、退出。
- D3D11 后端。
- 文件选择器、剪贴板。
- 中文字体。
- 按 Gate 5 验证 Windows 上的同一组语言行为，记录无偏好及已有偏好的启动结果。
- DPI 缩放。
- 鼠标滚轮。
- 大模型性能。
- 杀毒软件/系统权限导致的文件问题提示。

## P10-03 文档与发布
- README：功能、截图、支持范围、已知限制。
- DEVELOPMENT：环境、构建、测试。
- RELEASE：版本号、构建产物、校验和。
- 不把真实 PDM 测试样本放进发布包。
- 依赖许可证核查。
- 记录 Go/MyGo/Lobe MyGo 的实际版本。
- 明确哪些 PDM 版本经过真实样本验证。
- 明确 MySQL 版本和类型映射限制。
