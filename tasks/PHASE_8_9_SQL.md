# Phase 8～9：MySQL SQL Generator 与导出

## P8-01 MySQL 类型映射
整理 PDM 类型到 MySQL 类型的映射表。
区分别名、长度、精度、小数位、无符号、字符集/排序规则（如模型提供）。
对未知类型输出诊断，默认阻止静默生成错误 DDL。
输出 `docs/MYSQL_TYPE_MAPPING.md`。

## P8-02 单表 DDL
生成字段、NULL、DEFAULT、AUTO_INCREMENT、PRIMARY KEY、表注释。
标识符使用反引号并正确转义反引号字符。
字符串默认值和注释正确转义。
不能将原始默认值一律当作字符串；要区分表达式、NULL、数值、字符串和当前时间函数。

## P8-03 索引与约束
生成唯一索引、普通索引、复合索引及字段顺序。
检查索引类型和前缀长度；不支持属性必须报告。
主键不能重复生成。
外键保留约束名和字段映射。

## P8-04 全库依赖策略
先生成所有 CREATE TABLE，再生成 ALTER TABLE ADD CONSTRAINT 外键。
处理循环依赖。
识别缺失目标表、缺失目标列、类型不匹配等风险并报告。
如模型存在多个物理数据库或多个 Schema，必须先确认数据库边界和命名规则，不能合并错库。

## P8-05 全库初始化 SQL
生成：
- CREATE DATABASE IF NOT EXISTS。
- 字符集/排序规则（有可靠来源或用户明确设置时）。
- USE。
- 全部表 DDL。
- 表和字段注释。
- 索引、主键。
- 外键。
输出稳定排序，重复运行生成结果一致。

## P9-01 SQL 预览
独立页面/标签页显示全量 SQL，语法高亮（若 Native UI 能力不足，可先做等宽字体和关键字样式，不引入 WebView）。
显示统计和警告。
使用 P1-04 的双语资源显示预览标题、统计、警告和操作按钮。切换语言时已生成的 SQL 文本保持一致。

## P9-02 复制与导出
全部复制、保存 `.sql`、文件名建议。
导出前显示错误/警告摘要。
复制和导出的应用提示支持双语。原生保存面板的系统控件使用系统语言，导出的 SQL 内容与当时界面语言无关。

## P9-03 Golden Tests
为不同类型、默认值、转义、注释、索引、外键、循环依赖建立 golden tests。
确保单表 DDL 与全库中对应表 DDL 一致。

## P9-04 MySQL 8.0 集成测试
使用隔离的临时 MySQL 8.0 实例执行生成 SQL。
检查数据库、表、列、类型、NULL、默认值、注释、索引、主外键。
未实际执行时明确标记 NOT RUN。
