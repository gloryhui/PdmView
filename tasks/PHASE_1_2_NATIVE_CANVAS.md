# Phase 1～2：Native UI 与大型画布原型

## P1-01 Native UI 最小窗口
步骤：
1. 使用官方当前 API 创建原生窗口。
2. 设置窗口标题、最小尺寸、关闭生命周期。
3. 验证 macOS Apple Silicon 启动。
4. 确认原生窗口句柄有效、`Window.Page() == nil`，应用未创建 WebView。
5. 记录窗口截图和启动方式。

验收以本机真实启动、原生 UI、未创建 WebView 和正常关闭为准。系统框架加载按 [架构规范](../ARCHITECTURE.md#原生-ui-与平台运行时边界) 记录。

## P1-02 Painter/Canvas 验证
步骤：
1. 绘制矩形、圆角矩形、线、路径、文字。
2. 绘制虚线和贝塞尔曲线（API 支持时）。
3. 验证 Clip、Transform。
4. 验证高 DPI 文字清晰度。
5. 验证 Canvas/纹理缓存机制。
6. 测试中文、英文、数字混排。
7. 确认绘制 API 的线程要求。

验收：形成可重复运行的 Painter Demo，记录实际 API。

## P1-03 三栏布局原型
实现左侧导航、中间 Canvas、右侧详情占位。
前置任务为 P1-04。左侧导航、画布控件和右侧详情占位通过统一文案入口取得文本。
验收：两种语言下窗口缩放时布局合理，分隔区可用；无网页布局。

## P1-04 界面国际化基础与语言偏好

前置任务为 P1-01。在最小原生窗口验证机制，完整业务界面的翻译随各功能阶段交付。

1. 建立随应用打包的 `zh-CN` 和 `en` 资源、稳定消息键和参数格式化入口。
2. 按 [产品规范](../PROJECT_BRIEF.md#首版界面语言) 解析已保存语言及系统默认语言，按 [架构约定](../ARCHITECTURE.md#界面国际化与偏好) 读取和保存本地偏好。
3. 增加原生菜单「设置 → 语言」/「Settings → Language」，用 `简体中文` 和 `English` 作为固定选项名称，显示当前选项。验证最小窗口中的菜单及一处应用文案同时刷新。
4. 对系统语言读取、原生菜单刷新与偏好写入的实际行为保留验证记录。

验收：

- 单元测试覆盖两套资源键和参数一致性、英文回退、已保存选择优先、中文及其他系统语言的默认选择、配置缺失或无效，以及保存失败保留上次偏好。
- 在 macOS 原生窗口中双向切换，菜单和窗口文案即时更新，无需重启。退出再启动后恢复已保存的语言。Windows 实机验收列入 P10-02。

## P2-01 模拟图数据生成器
生成 50/150/300/500 个表节点，以及按比例生成的关系线。
支持长表名、长字段名、中文、稀疏/密集布局、关系交叉。
输出固定 seed，保证测试可复现。

## P2-02 坐标变换
实现 World、Viewport、Screen 三套坐标。
支持平移、缩放、鼠标位置锚定缩放、适应窗口、显示全部。
验收：缩放锚点稳定，反向坐标转换正确，有单元测试。

## P2-03 HitTest 与空间索引
先定义统一空间接口，再选择 R-Tree 或其他方案。
支持节点和边查询；对比线性扫描与空间索引。
验收：点击命中正确，边界条件有测试。

## P2-04 Viewport Culling 与 LOD
只查询并绘制视口可见节点和边。
远景显示简化节点；中景显示关键字段；近景显示完整字段。
验收：缩放阈值稳定，切换不闪烁；视口外对象不执行详细绘制。

## P2-05 性能基准
记录每个规模的 FPS、P95 帧耗时、CPU、内存、可见节点/边数、缓存命中率。
测试设备、系统、分辨率、构建模式和操作步骤必须记录。
验收：形成 `docs/CANVAS_BENCHMARK.md`，不允许只写“流畅”。
