# Phase 7：详情、搜索与复制

## P7-01 主窗口三栏布局
左侧模型树/搜索，中间 ER 画布，右侧详情。
支持合理的最小宽度、分隔线和窗口缩放。
不使用网页布局或 WebView。
复用 P1-04 国际化机制。导航、搜索、详情、画布控件和复制反馈提供两套文案。带模型切换语言时保留当前 Diagram、选中对象与视口，验收时检查中英文标签可读。

## P7-02 模型树与 Package
展示模型、Package 层级和表；支持展开折叠。
点击表时定位画布并选中。
搜索结果可定位对应表。

## P7-03 表详情
展示：
- 表名称、Code、注释、Package。
- 字段名称、Code、类型、长度、精度、小数位、NULL、默认值、自增、PK/FK、注释、顺序。
- 索引名称、唯一性、字段及顺序。
- 外键名称、当前字段、关联表、关联字段。
长列表可滚动；数据来自统一 Domain Model。

## P7-04 搜索与定位
支持表名、Code、字段名、字段 Code、注释搜索。
结果点击后平滑定位、选中表并展示详情。
搜索不得阻塞 UI。

## P7-05 完整信息复制
复制格式采用稳定、可读的 Markdown 或纯文本。
包括表信息、所有字段、索引、主键、外键。
字段顺序与 PDM 一致。
剪贴板 API 必须经当前 MyGo/平台实现验证。
复制失败应有错误提示。
单表 SQL 复制调用统一 SQL Generator。
同一张表在两种界面语言下复制的结构化表信息与 SQL 输出应分别一致。
