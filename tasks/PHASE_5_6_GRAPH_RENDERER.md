# Phase 5～6：Graph Engine 与 ER Renderer

## P5-01 Graph Node/Edge
定义 Node、Edge、Geometry、DiagramGraph；保存原始对象 ID 和 Diagram ID。
验收：节点/边可追溯回 PDM 对象。

## P5-02 坐标变换
封装 WorldToScreen、ScreenToWorld、ViewportBounds、ZoomAt、FitBounds。
所有交互和绘制统一使用该模块。

## P5-03 空间索引
为节点边界建立 R-Tree 或经基准验证的空间索引。
支持更新、删除、视口查询、点查询。
禁止每次鼠标移动线性扫描全部节点。

## P5-04 命中测试
节点优先于边；选中节点时正确返回 Table ID；边命中采用屏幕空间容差。
测试缩放状态下命中精度。

## P5-05 关系线几何
优先原始路径；缺失时自动路由。
避免关系线穿越节点；处理多条线共享端点、交叉和循环关系。
不得擅自推断模型中不存在的关系基数。

## P6-01 表节点绘制
标题、表名、编码、字段行、类型、PK/FK 标记、选中/悬停状态。
提前测量文本和计算尺寸；长字段和大量字段应可裁剪或滚动/LOD 展示。

## P6-02 关系线绘制
先绘制边，再绘制节点，避免关系线覆盖文字。
支持方向箭头或关系标记（原始数据可确认时）。
选中表时高亮相邻边。

## P6-03 LOD/缓存/裁剪
实现视口查询、远中近景、文字测量缓存、静态背景缓存。
缓存必须有上限和淘汰策略；模型切换时清理。
禁止无限尺寸的全画布位图。

## P6-04 多画板与视口工具
多 Diagram 切换；缩放、平移、适应窗口、显示全部、原始布局复位。
切换 Diagram 时保持独立视口状态可作为后续增强，首版至少正确切换内容和布局。

## P6-05 性能验收
使用固定数据集和固定操作脚本，按 QUALITY_GATES.md 测试。
输出真实报告；不达标先优化，不得降低验收规模。
